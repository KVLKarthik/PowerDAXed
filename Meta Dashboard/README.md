📢 Meta Ads Performance Dashboard (Power BI)
This project is a Power BI marketing analytics dashboard designed to analyze advertising performance across Facebook and Instagram (Meta Ads).
The dashboard provides end-to-end visibility into reach, engagement, conversions, audience behavior, and budget efficiency, enabling data-driven campaign optimization.

📊 Dashboard Structure

KPIs
Impressions,Clicks,CTR,Engagements,Engagement Rate (%),Purchases,Conversion Rate (%),Purchase Rate (%),Total Budget,

🔧 Techniques & Tools Used


DAX (Calculated measures & KPIs),
Time Intelligence
Conditional formatting
Slicers & dynamic filters
Donut charts, bar charts, stacked visuals, matrices, maps, tooltips

📍 Data Source

Meta Ads (Facebook & Instagram) marketing data

Time period: Campaign-level data (sample / anonymized)

📌 Insights Targeted

Platform effectiveness (Facebook vs Instagram)
Audience engagement and conversion patterns
Best-performing ad formats
Optimal ad scheduling windows
Budget allocation efficiency
